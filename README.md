# Password Strength Analyzer

A simple command-line password strength analyzer built with Python.

## Features

- Checks password length
- Detects uppercase and lowercase letters
- Detects numbers
- Detects symbols
- Calculates a password strength score
- Classifies passwords as Weak, Medium, or Strong
- Provides suggestions for improving weak passwords

## Run

```bash
python3 password_analyzer.py
```

## Example

```text
Enter your password: Hello123!

Length: 9
Has uppercase: YES!
Has lowercases: YES!
Has number: YES!
Contains Symbol: YES!
Score: 5
Strength: Strong
```
